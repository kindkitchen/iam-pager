# Durable session slice delivered

Added `DenoKvSessionRepository` with versioned ISO-date serialization, a logical
session record plus credential-hash index, and native atomic commits for
creation, monotonic renewal, bounded authentication-attempt save/consume,
credential rotation, CSRF-bound logout, and revocation. Contended operations
retry against fresh versionstamps; one-use and one-winner behavior remains valid
across repository instances. Raw browser bearers and OAuth state remain absent.

Session records and credential indexes receive an absolute-lifetime Deno KV TTL.
Idle and absolute expiry are still checked by `SessionService` because KV expiry
is lazy; logout/revocation atomically removes bearer lookup immediately and
retains only the inaccessible primary record until its TTL.

Added one implementation-agnostic repository conformance suite and ran both
memory and Deno KV through it. Environment composition defaults to memory and
accepts `IAM_PAGER_SESSION_STORAGE_BACKEND=deno-kv` only with Deno KV ownership,
inheriting its path/default database. Updated README, specification, and
retention/deployment guidance. Verification target: check, 261 tests, and
production build.

before implementing durable `ContentRepository`; preserve atomic replacement
without assuming source plus derived data fits one KV value.
