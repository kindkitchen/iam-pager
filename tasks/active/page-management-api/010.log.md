# Removed the superseded page stack

Completed plan step 11. Deleted the locator-only publishing service, namespace
publishing authorizer, guest/direct HTTP adapters, legacy `ContentRepository`
memory and Deno KV implementations, their conformance suite, and all tests tied
to that obsolete path. Removed the superseded content-level page record and
repository contracts while retaining the reusable content handler, metadata, and
delivery payload interfaces. Migrated direct response, active-content isolation,
attachment filename, and explicit failure coverage to the replacement delivery
boundary.

`PageService`, `PageRepository`, and the composed management/direct HTTP
boundaries are now the only page mutation, persistence, and delivery path. README,
specification, and changelog were updated to match. Check and build pass; all 345
remaining tests pass.
