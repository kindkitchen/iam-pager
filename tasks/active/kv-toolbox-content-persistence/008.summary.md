# KV gateway and codec checkpoint complete

Phase 1 is complete. `@kitsonk/kv-toolbox` 0.31.0 is exactly pinned behind
project-owned record, binary-staging, native-atomic, and lifecycle interfaces.
The production gateway alone owns `KvToolbox`; ordinary operations delegate to
it, while `native_atomic()` delegates directly to `toolbox.db.atomic()` and
returns one all-or-none Deno atomic operation.

The selected identity, namespace, session, legacy page, and manual database
schema adapters now depend on the project gateway instead of receiving raw
`Deno.Kv`. Their unchanged conformance proves that the rewire preserved current
records and behavior. The rejected, unselected Kvdex asset prototype remains
only until its replacement reaches parity.

Binary staging now detaches non-empty input, requires an unused complete key,
delegates segmentation, reconstructs and compares the full result before
success, and removes known failed staging best-effort. Read-back verification is
required because a later toolbox batch can fail after an earlier successful
commit result. Contract tests cover 1 MiB and the accepted 16 MiB PDF bound,
fresh gateway wrappers, later-batch interruption and retry, missing metadata or
chunks, truncation, malformed metadata, removal, native CAS, and handle closure.

A separate `v8-1` content-data codec uses the runtime's V8 serializer behind a
versioned interface. It round-trips current Markdown and PDF data and matches a
retained byte fixture produced by the superseded prototype, so Phase 2 can move
manifests without silently changing payload encoding.

`deno task verify` passes all 509 tests, and `deno task build` passes. No runtime
backend selection, database schema/version, stored record, migration, or
production data changed.

Next: replace the unselected Kvdex immutable-asset adapter with a gateway-backed
manifest repository, preserving random staging, length/SHA-256/codec checks,
native manifest CAS, ambiguous-outcome retention, conflict isolation, and legacy
keyspace coexistence. Remove Kvdex only after equivalent and 16 MiB fault tests
pass; the raw page adapter remains selected.
