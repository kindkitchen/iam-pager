# Completed the local Google consent browser flow

Added a Fresh-independent `GoogleMockConsentHttpHandler` and development-only
`GET /auth/google/mock-consent` route using gauth 0.4.1's package renderer. The
route exists only for explicit loopback local mode, requires the exact generated
state, scope, and configured callback query, and uses no-store, no-referrer, and
restrictive content headers. Original mode returns not found.

The integration test now drives one browser cookie through start, rendered
consent, callback, identity creation, logical-session upgrade, and bearer
rotation without network access or credentials. It verifies that the rotated
cookie resolves the same authenticated logical session and that the stale guest
bearer cannot. All 161 tests pass.
