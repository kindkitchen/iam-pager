# Implement the session lifecycle core

Added interface-first session models, injectable clock/ID/credential generation,
`SessionRepository`, `MemorySessionRepository`, and `SessionService`. The core
creates guest sessions for invalid credentials, persists credential hashes only,
renews on a bounded threshold, rejects expired/revoked state, atomically
upgrades a stable logical session while rotating its bearer, rejects stale
concurrent upgrades, and supports revocation.

Added ten focused lifecycle and concurrency tests. Reserved `auth` as a platform
namespace and documented the in-memory/restart limitation. Cookie transport and
Fresh request middleware remain the next phase-1 slice.
