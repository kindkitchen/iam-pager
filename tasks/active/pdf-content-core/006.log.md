# Transport-independent PDF handler milestone

Added and composed the `pdf` handler with bounded detached byte validation,
fixed media type, safe filename/version metadata, inline and attachment profile
support, immutable render output, and a byte-free management projection. The
content-handler interface now separates publish input from management output, so
`md-page` retains editable source while binary handlers can remain bounded.

Focused unit and process-local service coverage verifies malformed, non-byte,
and oversized rejection, supported versions, classic and stream xref tails,
filename policy, clone isolation, one logical query row, and identical bytes
through generic inline and attachment bindings. It also covers coherent
replacement/access and deletion across both endpoints. `deno task check` and all
490 tests pass; `deno task build` also
passes.

Remaining core work is generic application endpoint-set command wiring and
alternate-preserving rename/duplication with lifecycle and conflict coverage.
