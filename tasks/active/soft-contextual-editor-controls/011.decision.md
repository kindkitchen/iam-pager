# Reserve attached tabs for interchangeable content

Use one reusable exclusive-content switcher and attached-panel treatment for
Markdown/CSS and Raw/Steps because each selection replaces an interchangeable
content pane below it. Keep Split with preview/Full width as a detached
segmented layout control: it rearranges the same content rather than selecting
overlapping content. Keep the section-type picker distinct as well because
choosing a type mutates one draft's schema and can disable conversions; it does
not reveal a preserved interchangeable pane.
