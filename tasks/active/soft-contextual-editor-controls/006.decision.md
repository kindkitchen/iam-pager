# Measure section frames without enabling draft scripts

Whole section sizing must react to the actual Markdown, editable CSS, wrapping,
and viewport width; source-line estimates alone cannot satisfy that behavior.
Section preview frames therefore use `sandbox="allow-same-origin"` without
`allow-scripts`, allowing the parent editor to read rendered document height on
load and responsive width changes while draft scripts remain prohibited. A
cross-origin self-navigation is caught and retains its conservative estimated
height. The full-page live preview does not need parent measurement and keeps
the stricter opaque `sandbox=""` boundary.
