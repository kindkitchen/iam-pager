# PDF HTTP slice complete

Implemented a Fresh-independent multipart decoder and integrated it into the
existing page collection/item adapter without changing JSON Markdown. It
strictly validates framing, exact parts, media types, metadata shape, filenames,
and streaming byte limits before calling `PageService`. Managed replacement
retains CSRF and exact ETag conditions and atomically replaces bytes plus the
explicit endpoint set.

Direct delivery now receives the full request, retains session-derived private
access, emits request IDs and opaque revision validators, and maps PDF single
ranges, conditional requests, exact lengths, and endpoint-selected inline or
attachment disposition. The catch-all Fresh route remains a thin delegate.

HTTP, direct-delivery, bounded-stream, and composed-root tests cover create,
inspect, replace, stale requests, malformed input, byte identity, range success
and failure, conditional fallback, and attachment filenames. API, README,
specification, and changelog sources document the accepted contract.

Verification: 548 tests, `deno task check`, and `deno task build` pass.
