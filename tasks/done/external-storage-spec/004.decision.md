# Keep authoritative asset metadata local

Every asset keeps content type, media type, exact size, required SHA-256,
codec/schema version, and optional safe filename locally. An external source
replaces inline payload data with provider ID, connection ID, opaque object
reference, and an optional version hint. Provider metadata never overrides these
facts.

Delivery obtains the complete bounded payload and verifies size and checksum
before applying normal response/range behavior. This preserves asset
immutability even if the provider object is edited in place. Treating provider
metadata as authoritative was rejected because it would let remote mutation
change a committed asset without a page revision.
