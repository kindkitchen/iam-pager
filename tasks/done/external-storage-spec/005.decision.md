# Require read and advertise optional write/delete

A registered external provider must implement normalized bounded read. Write and
delete are separately advertised optional capabilities. External publish and
replace are offered only for write-capable connections and never fall back to
inline storage silently. Page replacement/deletion never implies remote delete;
explicit cleanup must prove the asset unreferenced and handle providers without
delete.

Requiring every provider to write or delete was rejected because read-only
sources are a valid interface shape. Making read optional was rejected because
an object that iam-pager cannot retrieve cannot back delivery.
