# Start with namespace reservations on Deno KV

The first durable vertical slice is `NamespaceRepository` on Deno KV. Its
atomic case-insensitive reservation contract and reusable conformance suite are
already settled, so the backend can prove durable serialization, native atomic
claiming, owner indexing, and composition-root switching without changing
business services.

Only namespace reservations become durable in this slice. Content, sessions,
and identities remain explicitly in-memory; a global storage switch would
misrepresent that boundary. Unset configuration continues to select memory.
