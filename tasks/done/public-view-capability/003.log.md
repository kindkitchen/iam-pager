# Status: active -> done

Completed DS-VIEW end to end.

## Logic and storage

- Added visitor-safe `PublicPageViewer` and `PublicPageLister` interfaces to
  `lib/page/`; summaries omit page IDs, revisions, access controls, content
  source, and owner identity.
- `PageService.view_public` resolves public managed or trial pages, renders a
  supported payload, and collapses private, missing, forbidden, malformed, and
  incoherent pages into `not_found`. A namespace-only locator resolves its
  default page.
- `PageRepository.list_public` performs bounded, namespace-bound opaque cursor
  pagination over public managed pages only. Memory and Deno KV implementations
  skip private and trial locator entries without shortening result pages; their
  shared conformance suite covers ordering, eligibility, pagination, malformed
  and cross-namespace cursors, and structural validation.

## Site projection

- `CreatorPublicPageViewPresenter` is web-independent and derives sandbox
  preview/fallback state, direct/default links, and bounded other-public-page
  links. Trial views deliberately expose no creator listing.
- `/site/<locator>` is a thin Fresh route over that presenter. It returns a real
  non-disclosing 404 for unavailable views, confines supported HTML to a
  sandboxed no-referrer iframe, and owns all platform navigation outside the
  creator frame.
- Specs, open-question decisions, README, styles, composition, and CHANGELOG
  were updated together.
