# Plan steps 2-4 delivered: page model, repository contract, memory backend

Implemented the storage foundation of [[003.plan]] as one coherent fragment:

- `lib/content`: `ContentTypeHandler.to_input` recovers the safe editable
  input from stored data; `MdPageHandler.to_input` returns only `{ md, css? }`
  and round-trips through `validate` without exposing derived html.
- `lib/page/model.ts`: `PageRecord` with opaque route-safe `page_id`,
  publisher-cased locator, trial/managed stewardship, public/private access,
  positive revision, page-level timestamps, and `page_record_violation`
  enforcing the invariants (trial implies public, private implies managed,
  non-empty managed owner).
- `lib/page/interfaces.ts`: `PageRepository` with find by locator/id, bounded
  owner listing, atomic `put_trial` (create-or-replace of absent/trial only,
  preserving id/created time, incrementing revision), `create_managed`
  (replaces trial, retires its id, conflicts with managed), revision-bound
  `replace_managed` (omitted content = access-only update) and
  `delete_managed`. Missing/trial/foreign pages collapse into one
  non-disclosing `not_found`; structurally invalid requests throw.
- `lib/page/cursor.ts`: deterministic sort key (namespace, default-first,
  name, id) and strict base64url continuation cursor bound to the active
  namespace filter; invalid/padded/oversized/mismatched cursors are rejected.
- `lib/page/memory-repository.ts`: synchronous check/set mutations, cloned
  boundaries, passes the full conformance suite.
- `lib/page/repository-conformance.ts`: 27 backend-neutral tests covering
  identity, casing, stewardship, conflicts, revisions, listing/pagination,
  concurrency races (one managed winner, trial cannot overwrite managed,
  one replace/delete winner per revision), large/binary round trips, and
  programming-error rejection. Deno KV will run it unchanged.

Gates: fmt/lint/check, 342 tests (was 307), build all pass.

backend.
