# Review: MdPage handler and in-memory repository

Reviewed the code landed with [[005.analysis]]: `lib/content/md-page.ts`,
`lib/content/memory-repository.ts`, `PageRecord` + repository interface rework,
14 new tests (37 total), `deno task check` clean.

## Holds up

- The `ContentTypeHandler` contract survived its first implementer without
  signature changes; sync `derive` was the right call (gfm renders
  synchronously).
- Repository rework closes review item 6 from [[004.review]]: original-cased
  `Locator` is stored in `PageRecord`, keys derived internally, verified by the
  casing-preservation and cross-case replacement tests.
- Both injection paths are covered by tests: script through markdown (sanitized
  by `@deno/gfm`) and `</style>` breakout through css (neutralized by `\3c`
  escaping). Default-vs-named page key collision is tested.

## Flaws found, accepted for now

1. **`render` trusts `data.html`.** Sanitization lives in `derive`; a hand-built
   `MdPageData` bypasses it. The publish use-case must be the only producer of
   stored data and must always run `validate -> derive`. This is the invariant
   to enforce (and test) in the next step.
2. **Meta/payload reconciliation is unresolved.** `ContentMeta.size_bytes` and
   `media_type` overlap with what `render` returns, and for MdPage the delivered
   document is built at delivery time. QT-ROUTING forbids stale metadata next to
   fresh payload. Decision needed in the publish/deliver step: compute meta from
   `render` output at publish time and treat `render` as deterministic.
3. **Repository returns live references.** Mutating a returned `PageRecord`
   mutates the store. Acceptable for the in-memory guest slice; a
   `structuredClone` at the boundary is the cheap fix if it ever bites.
4. **No `<title>` in the raw document.** Cosmetic; a later slice can derive one
   from the first heading or the locator.
5. **`--allow-env` needed for tests** because `@deno/gfm`'s transitive deps
   probe env vars at import. Contained to the test task; the Fresh server
   already runs with `-A`.

## Still open from [[004.review]]

- Item 2: forbid `/` in `namespace` at model level (charset validation).

## Verdict

Contracts are stable and both first implementations are covered. Next step:
publish/deliver use-case functions (owning the validate -> derive invariant and
the meta decision), then HTTP wiring.
