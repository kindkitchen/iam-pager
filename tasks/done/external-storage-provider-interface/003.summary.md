# Provider interface family implemented

Added `lib/external-storage/` with bounded `ExternalContentRef` validation,
mandatory read/stat and optional write/delete provider operations, normalized
`external_content_missing` and `external_source_unreachable` results, and a
read-only provider resolver registry that rejects invalid IDs and incoherent
capability declarations.

A reusable conformance suite covers bounded complete fetches, stat consistency,
missing/unreachable normalization, optional writes, explicit deletes, and value
isolation. `MemoryExternalStorageProvider` passes it and supplies deterministic
seeding and missing/unreachable fault injection for later tasks.

Updated README, changelog, and external-storage specifications. `deno task
verify` passes: 568 tests (13 steps).

Next: `content-asset-external-source` can consume `ExternalContentRef` while
keeping local asset metadata authoritative.
