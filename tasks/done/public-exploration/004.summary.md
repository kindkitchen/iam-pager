# DS-EXPLORE first version complete

Added `PublicPageExplorer` through `PageService` and `PageRepository`, with
normalized namespace/page-name substring filters, deterministic ordering, and
opaque continuations bound to both query fields. Memory and Deno KV implement
the same behavior over current records and pass shared conformance for browse,
separate/combined search, pagination across ineligible rows, cursor isolation,
private/guest exclusion, and immediate public-to-private removal.

Added a web-independent site presenter and thin GET form/result projection on
`/` and `/site`. Results expose no management identity and link to the DS-VIEW
wrapper and direct content. Settled and updated DS-EXPLORE, CP-EXPLORE,
EX-EXPLORE, OQ-EXPLORE, QT-SEARCH, README, and CHANGELOG.

Verification: `deno task check`, all 384 tests, and `deno task build` pass.
