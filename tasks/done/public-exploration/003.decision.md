# Settle OQ-EXPLORE on names and namespaces

The first exploration version is deterministic browse plus case-insensitive
substring search by namespace and page name. Either field can be used alone;
together they use AND semantics. Default pages match browsing and namespace
search, but not page-name search.

Tags are deferred until `management-expansion` supplies page tags. Text-content
extraction/indexing, relevance, and view-count sorting remain later work. The
public contract stays independent of the current repository scan so an index can
replace it without changing locators or visitor summaries.
