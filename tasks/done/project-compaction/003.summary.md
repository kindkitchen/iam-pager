# Current project baseline

The product remains deterministic direct content delivery plus guest publishing, creator namespace ownership/management, public exploration, and Markdown/PDF endpoint profiles. Application behavior remains outside Fresh and UI components.

`PageAggregateRepository` is now the sole page persistence contract. Memory and Deno KV implement it directly. The raw schema-v1 page repository, compatibility branch in `PageService`, v1-to-v2 migration/readiness flow, generic database release framework, migration-only staging mode, and related tests/configuration were removed. Current Deno KV page storage starts in its own schema-v1 aggregate keyspace and uses the single `deno-kv` selector.

README, API, specification, open scope, changelog, and source comments now describe current requirements rather than delivery history. Historical delivery-slice/refinement documents were removed. Closed task entries remain unchanged under the task system's immutable-history rule.

The worktree is about 10,900 lines smaller overall: `lib/` fell from 40,787 to 32,490 lines and product documentation from roughly 4,041 to 1,152. The regression suite now contains 454 current tests instead of 579 after removing 125 compatibility/migration tests. `deno task verify` and `deno task build` pass.
