# Completed tags and filtering core milestone

Implemented bounded canonical managed-page tags throughout the HTTP-independent
page model, service, memory repository, and Deno KV repository.

- Managed create and exact-revision update normalize up to ten 1–32 character
  tags into a lowercase sorted unique set; update can replace or clear tags.
  Trial pages remain untagged, rename preserves tags, and duplicate copies the
  exact source tag snapshot.
- Managed listing now AND-combines optional namespace, page-name substring,
  access, and exact-tag filters. Public exploration adds one exact tag with AND
  semantics alongside its existing name queries.
- Managed and exploration cursors bind the complete active filter scope. Shared
  repository conformance covers filtering across eligibility gaps, pagination,
  scope mismatch, mutation, and invalid raw requests on memory and Deno KV.
- Deno KV writes tags into schema-v1 envelopes and reads older envelopes without
  the optional field as untagged. No migration or secondary index is required.
- Updated README, page API status, CHANGELOG, and DS-MANAGE/CP-MANAGE/EX-MANAGE/
  addressing/search specifications. The current API and site deliberately do
  not expose the new fields yet.

Validation: `deno task test` passes 415 tests and `deno task build` passes.
`deno task check` passes after formatting the updated documentation.

Next: implement explicit per-page-result bulk access and deletion contracts in
