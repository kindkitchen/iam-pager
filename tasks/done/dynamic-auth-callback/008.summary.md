# Dynamic local mode no longer needs static URLs

Completed the final configuration correction. When local mode has
`IAM_PAGER_GOOGLE_AUTH_REQUEST_HOST_PATTERN`, both
`IAM_PAGER_GOOGLE_AUTH_REDIRECT_URI` and
`IAM_PAGER_GOOGLE_AUTH_MOCK_CONSENT_URL` are optional. Callback and mock consent
are composed lazily from each allowlisted HTTPS request origin. If compatibility
fallback URLs are supplied, both must be present and retain same-loopback
validation. Local mode without a pattern still requires the original static URL
pair.

The application integration test now proves the full dynamic preview flow with
only mode and host pattern configuration: start, same-origin mock consent,
callback, and authenticated session upgrade. README contains the minimal preview
environment. Verification passed: `deno task check`, 177 tests, and
`deno task build`.
