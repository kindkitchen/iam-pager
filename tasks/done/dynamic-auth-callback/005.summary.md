# Local preview callback support completed

Corrected the feature for its intended deployment: local mock authentication now
accepts `IAM_PAGER_GOOGLE_AUTH_REQUEST_HOST_PATTERN`. An allowlisted HTTPS
preview origin supplies both `/auth/google/callback` and
`/auth/google/mock-consent`; the consent boundary verifies the selected callback
is allowlisted and same-origin before rendering. Static localhost development
remains unchanged when the pattern is absent or empty.

The dynamic local browser integration now covers start, package-rendered consent,
callback, and authenticated session upgrade on the preview origin. Documentation
includes a complete local-preview environment example and warns that every
matched host deliberately exposes fake sign-in. Original mode retains its
provider-registration warning.

Verification passed: `deno task check`, 177 tests, and `deno task build`.
