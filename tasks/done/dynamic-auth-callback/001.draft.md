# Dynamic preview authentication callback

Add an optional environment regex that allows selected dynamic request hosts to
override the configured Google callback origin. Do not trust Origin or Referer
headers; use the server request URL, constrain it with a full host match and
HTTPS, reject mismatches, and preserve static production behavior when unset.
The provider token exchange must use the same redirect URI selected at start.
