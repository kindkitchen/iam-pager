# Dynamic Google callback completed

Added `IAM_PAGER_GOOGLE_AUTH_REQUEST_HOST_PATTERN` for original Google mode.
Unset or empty preserves the configured callback. When enabled, the complete
case-insensitive `Request.url` host must match, HTTPS is mandatory, and an
untrusted host fails before authentication orchestration. `Origin` and
`Referer` are not used. Callback-specific gauth services ensure authorization
and token exchange use the same redirect URI without an unbounded host cache.

Updated README, authentication specification, quality requirements, and
CHANGELOG. Added seven tests covering static behavior, trusted and hostile
hosts, invalid configuration, composition wiring, and callback-specific token
exchange. Verification passed: `deno task check`, 175 tests, and
`deno task build`.

Google still requires each resulting callback URI to be accepted by its OAuth
client; the application regex cannot provide provider-side wildcard support.
