# Regression review: approved

The browser/server boundary is restored.

- No project source directly imports `node:*`.
- `PageEditor` and the island no longer import `MdPageHandler`, `@deno/gfm`,
  `sanitize-html`, or any server content module.
- The browser depends on the `PagePreviewer` interface and a Fetch-based
  implementation; rendering remains server-owned and uses the existing
  `MdPageHandler`.
- Preview requests are debounced, abort stale work, are bounded at 96 KiB,
  validate through the content handler, use `no-store`, and never write to the
  repository.
- Shared bounded body reading was extracted without changing guest publish
  behavior; all existing publishing tests pass.
- The production island fell from about 1,009 KiB minified to 8.26 KiB. The
  client build no longer emits the large-chunk or sanitizer compatibility
  warnings.
- `deno task check`, all 80 tests, production build, direct preview smoke test,
  transformed client graph inspection, and headless Firefox rendering passed.
  Firefox reported no MIME, `NS_ERROR_CORRUPTED_CONTENT`, or
  `node:url`/`node:path` module errors.

The server build still contains `@deno/gfm` and its npm internals by design;
they execute only under Deno and are no longer exposed as browser modules.
