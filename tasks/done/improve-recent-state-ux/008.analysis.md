# Browser runtime boundary regression

The project source contains no direct `node:*` import. The regression came from
`PageEditor` importing `MdPageHandler` into the client island. `@deno/gfm`
depends on npm `sanitize-html`, which loads PostCSS modules requiring `path` and
`url`; Vite exposed those as `/@id/node:path` and `/@id/node:url`, and Firefox
correctly rejected the empty 404 responses.

Replacing those imports with `Deno.*` inside the island would still violate the
browser boundary because browser modules do not have the Deno namespace. Keep
`MdPageHandler` server-side and expose a bounded, UI-internal preview adapter;
the island should depend only on a preview interface implemented with browser
Fetch and AbortController APIs.
