# Improve UX on recent state

Importance: **not important**. This task intentionally changes only the current
guest publishing UI; it must not alter locator validation, publishing,
replacement, storage, delivery, or API behavior.

Deliver a mobile-first page creation surface with:

- a prefilled randomized namespace and an initially empty page name;
- a Random helper above both locator inputs, using grammatical four-word
  combinations and numeric fallback for locally repeated combinations;
- a Page editor with Markdown, CSS, and live preview areas plus All, Preview,
  and CSS view modes;
- editable element-oriented CSS presets whose selection replaces the entire CSS
  draft;
- live preview generated through the existing Markdown content representation.

A true “already in use” lookup is out of scope: the current guest endpoint
intentionally replaces pages and exposes no availability query.
