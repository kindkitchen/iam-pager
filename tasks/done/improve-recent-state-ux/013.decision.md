# Keep draft preview simple and local

The unpublished preview does not duplicate publish-time sanitization. It renders
Markdown locally with the browser-compatible `marked` ESM module into the
existing fully sandboxed iframe. `MdPageHandler` remains the authoritative
validation, sanitization, derivation, and delivery path when publishing.

Removed the internal preview endpoint and all preview POST requests. This also
keeps Deno/server and Node-compatibility dependency graphs out of the browser
without introducing a second security policy.
