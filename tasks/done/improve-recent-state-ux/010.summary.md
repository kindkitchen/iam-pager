# Browser-safe live preview

Corrected the live-preview boundary after Firefox exposed transitive Node
compatibility imports in the browser graph. `MdPageHandler` now stays
server-side behind bounded `POST /site/api/preview`; the island uses the
`PagePreviewer` interface and a debounced, abortable Fetch adapter. The guest
publishing endpoint and domain behavior are unchanged.

Validation passed with 80 tests and Firefox. The production island is now 8.26
KiB instead of roughly 1 MB, with no server renderer or `node:*` references in
the transformed client modules. See [[009.review]].
