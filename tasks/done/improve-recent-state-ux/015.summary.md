# Final client-only editor behavior

Live Markdown/CSS preview is now a simple local draft representation using
`marked` inside the sandboxed iframe. It makes no HTTP request and does not
duplicate publishing security; `MdPageHandler` still validates and sanitizes
only when the user publishes.

Published links navigate in the current tab so browser Back returns to the
editor without changing raw locator delivery. Markdown is prefilled with a short
heading and workflow tip rather than showing `# Hello world` as a placeholder.

Validation passed with 78 tests, production build, client graph inspection, and
Firefox. See [[014.review]].
