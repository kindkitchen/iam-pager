# Authentication foundation through the Google adapter

Phases 1 and 2 are complete: every application-routed request has typed guest or
authenticated session state and a server-owned request ID; opaque cookie
transport is separate from process-local storage; authentication attempts are
bounded, hashed, session-owned, expiring, and one-use; generic start/callback
HTTP adapters upgrade the stable logical session with bearer rotation; and
CSRF-bound form logout atomically revokes access and establishes a fresh guest.
Identity uniqueness remains `(strategy_id, provider_subject)` behind interfaces.

Phase 3 now pins gauth 0.4.1 plus compatible Effect and includes the thin Google
adapter. It supplies exact scope/state/callback inputs, stores only the returned
PKCE verifier in attempt context, maps verified identity profile fields,
discards provider tokens, and hides gauth failures. All 153 tests pass. No
provider is registered yet.

Next: add startup-validated Google configuration, explicitly compose gauth's
local or original preset, register Google, and test mode selection without live
Google calls. Then add the development-only package-rendered mock consent route
and full local browser flow.
