# Completed final authentication acceptance

Extended the configured local integration through CSRF-protected logout. It now
proves the authenticated bearer is revoked, a distinct fresh guest session and
bearer are published, and both stale guest and stale authenticated bearers fail
to recover the upgraded logical session.

restrictive site-owned HTML contains only validated local retry/return links;
callback values and provider causes remain absent. The local failure integration
proves provider failure consumes the attempt, replay fails, and unrelated guest
session state survives.

guest upgrade with bearer rotation, provider-owned recovery, and logout to an
unrelated fresh guest. Aligned `CP-NAMESPACE` and `QT-AUTHORITY`: authentication
establishes identity but does not reserve namespaces or authorize publishing.

local consent -> authenticated navigation -> form logout -> fresh guest, with a
new bearer at both transitions. `deno task check`, all 165 tests, and
`deno task build` pass.
