# Completed Google preset composition and registration

Added startup-validated Google configuration with explicit `local` and
`original` modes. Composition loads only the selected gauth 0.4.1 preset,
materializes its exported interface, wraps it in `GoogleGAuthStrategy`, and
registers `google` in the multi-strategy registry. The shared service boundary
is asynchronous so dynamic preset loading remains at composition rather than in
provider-neutral logic.

Local fake authentication requires same-origin loopback callback and mock
consent URLs. Original mode requires a client ID and secret and rejects
non-HTTPS callbacks outside loopback. Missing or malformed values fail before
shared services are created without exposing values. `deno task dev` explicitly
selects local session and Google modes.

Added four configuration, local/original composition, and registration tests;
all 157 tests pass without network access or real credentials. The mock consent
route is intentionally still absent.
