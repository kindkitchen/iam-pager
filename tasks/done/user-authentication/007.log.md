# Add generic authentication HTTP boundary

Implemented provider-neutral `GET /auth/:strategy/start` and callback adapters
plus thin Fresh routes. The boundary builds the exact callback path, bounds and
disambiguates query values, burns recognizable state on invalid callback code,
maps outcomes to no-store browser-safe redirects/errors, and logs only request
ID, safe strategy ID, and internal category. Successful callbacks publish the
rotated session through request middleware so it supersedes any staged renewal
cookie. Added 6 tests; all 144 tests and `deno task check` pass.

The task remains active. Next: add session-bound CSRF and `POST /auth/logout`
that revokes the current authenticated session and establishes a fresh guest.
