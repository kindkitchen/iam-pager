# Add session-owned attempts and authentication orchestration

Completed the route-independent phase-2 core. Guest sessions now own at most
five live authentication attempts for 10 minutes; persistence keeps only a hash
of each 256-bit state plus strategy, exact callback URL, validated local return,
server-only provider context, and timestamps. Save and consume are atomic,
expired attempts are pruned, a sixth live attempt evicts the oldest, and
mismatched, cross-session, expired, concurrent, or replayed callbacks cannot
reuse state.

`AuthenticationService` now selects registered strategies, rejects unsafe local
returns, consumes attempts before provider exchange, saves stable external
identity, upgrades the logical session, and rotates the bearer credential. It is
wired behind `AuthenticationOrchestrator` at composition. Added seven focused
attempt/orchestration tests; all 138 tests pass. Next is generic start/callback
HTTP adaptation and CSRF-protected logout with fresh-guest establishment.
