# Add the pinned Google gauth adapter

Pinned `jsr:@kindkitchen/gauth@0.4.1` and the compatible direct Effect import
for manual `node_modules`. Added `GoogleGAuthStrategy` against gauth's exported
interface: authorization receives exact scope, application state, and callback
URI; only the PKCE verifier becomes server-side attempt context; callback output
maps the stable subject and profile while provider tokens are discarded. Missing
context and raw gauth failures collapse to the provider-neutral failure result.
Added 4 tests; all 153 tests pass.
