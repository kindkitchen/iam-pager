# Complete authentication core with CSRF-bound logout

Implemented the final phase-2 boundary: authenticated upgrades issue a 256-bit
synchronizer token, and bounded form-only `POST /auth/logout` validates that
token against the current repository record while atomically revoking the
session. Successful logout establishes a distinct guest logical session and
bearer, published through the central request middleware; stale, cross-session,
and replayed requests cannot revoke authenticated access. Diagnostics omit form
values and raw causes. Added 5 lifecycle/HTTP tests; all 149 tests and
`deno task check` pass.
