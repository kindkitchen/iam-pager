# External storage management surface complete

Added browser-owned connection list/connect/disconnect APIs with strict session
and CSRF rules and token-free metadata. `/site/manage` now shows Google Drive
connection state, reconnect/disconnect controls, and the dependent-assets
warning. Active write-capable connections are projected into publish and
revision-bound replacement controls.

Page create/update and PDF multipart contracts accept an optional provider
selector. `PageService` resolves the creator's active connection, validates and
renders canonical bytes, uploads through `put_content`, then commits a
payload-free external asset with local size, SHA-256, filename, media type, and
codec facts. Upload failure never falls back inline or mutates the page.

Updated README, API references, specifications, styles, changelog, API matrix,
and focused service/HTTP/presenter/component tests. `deno check`, lint, and the
focused tests pass.
