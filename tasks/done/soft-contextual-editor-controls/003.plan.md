# Reviewable implementation sequence

1. Define stable editor-view and section-density state outside the web
   representation, with focused tests for source exclusivity, layout semantics,
   and density reconciliation across source changes.
2. Rework the guest locator fields and Page editor shell: soft contextual
   labels, attached Random actions, collapsible source/preview workspace,
   Markdown/CSS source switching, split/full-width layout, and fullscreen
   preview.
3. Make guided section previews measure whole rendered content, expose
   compact/whole controls, and preserve each choice independently across edits
   and focus changes.
4. Review responsive and accessible behavior, synchronize
   README/specification/changelog, run all validation, record review, and mark
   the task done in the final review commit.
