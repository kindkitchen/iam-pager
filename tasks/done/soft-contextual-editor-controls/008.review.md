# Review-ready assessment

## Acceptance review

- Labels and optional actions use a subdued shared hierarchy; Random, Paste,
  Copy, and Clear are integrated with their input contexts.
- Markdown/CSS are exclusive panes in a mounted, collapsible workspace whose
  source and split/full-width layout state survives hide/show.
- Split places source and preview side by side where space permits; Full width
  puts preview below. Browser fullscreen enters, exits through its control or
  Escape, and announces state without replacing render status.
- Guided cards measure whole CSS-reactive content by default. Independent
  Compact/Whole state survives saved content and focus changes and follows move,
  merge, and removal operations.
- Mobile and desktop screenshots show no overflow or detached controls. Keyboard
  semantics, labels, pressed/expanded states, focus outlines, hidden states, and
  live status regions remain explicit.

## Boundary and risk review

Section measurement requires parent access to `srcdoc`; `allow-same-origin` is
limited to section frames without `allow-scripts`. Cross-origin self-navigation
falls back to an estimate. Full-page preview remains opaque and script-disabled.
Width observation is per frame, responds to layout/container changes, and
ignores height-only notifications to avoid resize feedback loops.

No blocking findings remain.
