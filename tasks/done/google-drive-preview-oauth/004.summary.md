# Credential-free preview Drive OAuth verified and hardened

Confirmed that Drive local mode with `IAM_PAGER_GOOGLE_DRIVE_REQUEST_HOST_PATTERN` does not require or read a redirect URI, client ID, or client secret. The callback and mock-consent origins come from the HTTPS request only after a complete host regex match; application routes retain fixed paths. Local mode remains mock-only and does not register the remote Drive provider.

Added parser and composition-root tests for credential-free preview startup, same-origin mock consent, hostile-host rejection, and provider absence. Original-mode credential errors now state that they apply when `IAM_PAGER_GOOGLE_DRIVE_MODE=original`, and direct local composition validates its static-or-dynamic URL invariant.

Updated `.env.example`, `README.md`, `docs/deployment-environment.md`, `docs/specification/external-storage.md`, and `CHANGELOG.md` with the complete preview profile and Deno Deploy variable import list.

Validation passed: `deno task verify` (667 tests) and `deno task build`.
