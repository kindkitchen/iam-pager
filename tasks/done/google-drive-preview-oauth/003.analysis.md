# Dynamic Drive OAuth already exists; deployment guidance is incomplete

`parse_google_drive_oauth_config` already returns a local dynamic configuration from `IAM_PAGER_GOOGLE_DRIVE_MODE=local` plus `IAM_PAGER_GOOGLE_DRIVE_REQUEST_HOST_PATTERN`, without reading the redirect URI, client ID, or client secret. The configured HTTP resolver derives the callback origin from the HTTPS request only after a full-host regex match, and uses the fixed Drive callback route.

The reported client-credential failure therefore means the runtime selected `original` mode. Existing preview documentation lists host patterns after an original-mode example but omits the required local mode assignments, and the Deno Deploy import example omits all Drive variables. Add explicit preview profiles, clearer mode-specific errors, and composition-root regression coverage.
