# Google Drive provider implemented

Added an injected Drive v3 HTTP gateway for bounded metadata/media reads,
multipart writes, and OAuth token refresh. `GoogleDriveExternalStorageProvider`
resolves credentials through `StorageConnectionRepository`, refreshes expiring
or rejected access tokens single-flight, persists rotated credentials, and
revokes invalid grants or access that remains unauthorized after refresh.

Drive 404/410, trash, definitive 403, version drift, and size drift normalize to
`external_content_missing`; rate limits, 5xx, transport failures, and unknown
provider failures normalize to `external_source_unreachable`, preserving safe
bounded retry hints. Upload verifies returned size and captures `md5Checksum` as
the provider version hint.

Original-mode composition registers `google-drive` in the immutable provider
registry. Local consent mode remains provider-free. An in-process fake Drive and
token server drives the shared provider conformance suite plus mapping, refresh,
revocation, bound, and upload tests without network access. README, external
storage specification, and changelog are current. `deno task verify` passes all
638 tests before the final single-flight test was added; its targeted suite also
passes with 16 tests.
