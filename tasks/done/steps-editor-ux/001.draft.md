# Requested Steps and CSS UX follow-up

- Steps line previews must update when the editable CSS changes.
- CSS editing needs lightweight syntax highlighting; a CDN dependency is
  acceptable.
- Line Type must no longer contain blank, bulleted-list, or numbered-list
  choices.
- List membership becomes an independent checkbox with a bulleted/numbered
  switch so Text, Heading, and Link can each be standalone or list items.
- An empty Text line replaces the dedicated Blank line concept.
