# Steps composition and CSS UX completed

The deterministic physical-line engine now models content type and optional list
marker separately. It recognizes and creates standalone or listed Text, Heading,
Link, and raw Markdown while preserving untouched source and existing list
prefixes. Empty physical lines are Text with an empty value; the dedicated Blank
and list content types no longer exist.

Steps previews use the existing `PagePreviewer` interface to render each line in
a lazy sandboxed frame with the current CSS. The modifier form exposes
Text/Heading/Link/Raw Markdown Type choices plus an independent `Is list item`
checkbox and Bulleted/Numbered switch. This supports list headings and links.

The CSS textarea remains the input source and is overlaid on Prism-highlighted
markup. Prism 1.29 is fetched from exact jsDelivr URLs with SRI; blocked CDN
loading falls back to aligned plain text.

Verification passed: `deno task check`, all 88 tests, production build, CDN
asset checks, scripted Chromium state/interaction checks, and desktop plus
mobile visual inspection.
