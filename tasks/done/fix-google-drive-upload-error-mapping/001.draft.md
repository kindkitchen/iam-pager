# Google Drive upload failure diagnosis

The Drive gateway classifies every non-rate-limit HTTP 403 as `missing`, which is appropriate for bounded read/stat disclosure but impossible for creation uploads. The provider consequently returns `external_content_missing`, and the publish UI says an external file could not be found even though it was trying to create one. Upload denial must retain non-disclosing read behavior while mapping write rejection to provider unavailability.
