# Fixed operation-aware Drive 403 handling

Google Drive read/stat 403 responses retain non-disclosing missing-file semantics. Multipart upload 403 responses now become provider errors and normalize to `external_source_unreachable`, so publication no longer claims that a not-yet-created file is missing. The fake Drive server and provider tests cover quota rejection. README, specification, and changelog were updated. `deno task verify` passes with 671 tests.
