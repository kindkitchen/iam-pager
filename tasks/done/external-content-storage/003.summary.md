# External content storage epic complete

Creators can connect Google Drive through separate storage consent, manage the
connection without exposing credentials, and choose active writable external
custody while publishing or replacing validated Markdown/PDF content.
Authoritative metadata and integrity facts stay local; provider bytes are
fetched, verified, and served through iam-pager. Missing/revoked/altered content
uses the bounded visitor fallback and owner repair flow.

The provider-neutral interfaces, memory and production Drive adapters,
encrypted connection persistence, payload-free assets, delivery health,
management API/UI, documentation, and regression boundaries are implemented.
