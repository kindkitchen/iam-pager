# Breadcrumb navigation foundation + prototype manage split

Landed the incremental navigation direction. Added `lib/ui/site-breadcrumb.ts`:
a logical `SiteLocation` model and a `SiteBreadcrumbPresenter` Interface that
builds a server-owned trail in raw code, rendered by
`components/SiteBreadcrumb.tsx`. Wired trails into home, the public page view,
and a new `/site/manage` route (`components/ManagePagesPage.tsx`) that hosts the
existing creator manager as its own navigable page; the landing links to it.
Breadcrumb props are optional, so existing component tests are unchanged. 558
tests, `deno task check`, and `deno task build` pass. Additive prototype: inline
management stays until the split is validated.
