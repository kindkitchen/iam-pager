# Drag merge implementation validated

Implemented `MarkdownSectionEditor.merge` so merge semantics remain independent
of the Preact representation. Non-code destinations retain the dragged primary
value through explicit `<br>` continuation lines; code destinations append it
inside the fence. Heading/list syntax and Link URLs from the source are
discarded, while continuation values survive later edits and type changes.

The pointer interaction reserves card edges for reordering and exposes card
centers as visually announced merge targets. Preview height follows physical
lines, and dirty edits on either affected card block a merge instead of losing
work. `Numbered` and `Is list item` now share one row.

Validation passed: `deno task test` (96 tests), `deno task check`, and
`deno task build`. The build retains its existing non-fatal
`sanitize-html`/`htmlparser2` export warning.
