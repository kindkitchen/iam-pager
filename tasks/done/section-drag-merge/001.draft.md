# Improve section drag interactions

- Keep `Is list item` and `Numbered` on one line.
- Add a visually distinct drop-into target while a section is dragged over
  another section.
- On drop, retain the destination section, append the source's primary value
  without its original Heading, Link, list, or code-block syntax, and remove the
  source section.
- Grow multi-line section previews and retain ordinary reordering and keyboard
  movement.
- Keep merge behavior in the Markdown section editor interface rather than in
  web-only state.
