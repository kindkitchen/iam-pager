# Merge values without HTML markers

Removed editor-generated HTML break tags after user feedback. A merge now
updates the destination draft directly: Heading, Text, Raw Markdown, and Link
label values combine with a space; multiline source values are flattened for
these one-line fields. Code block destinations append the unmodified source
value with a physical newline. The destination's type and modifiers remain
authoritative, and the source card is removed.
