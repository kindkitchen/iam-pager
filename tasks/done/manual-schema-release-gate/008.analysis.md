# Deployment context names vary

The live dashboard exposes Production, Preview, Build, and Local rather than the
Production, Development, and Build labels in current Deno documentation. Context
names are server-provided organization records, so Preview is the app's likely
name for the documented non-production runtime context used by Git branch and
revision-preview timelines. This can be confirmed by placing the non-secret
backend selectors in Preview and observing the Git Branch partition.

Local is an independent tunnel context: `deno ... --tunnel` pulls its variables
into the local process and can attach hosted local-development resources. It is
not used by cloud Build, Preview/Git Branch, or Production execution. Deployment
guidance now describes the semantic context and both observed labels instead of
requiring a context name that may not exist.
