# Detailed implementation tasks

1. **Section domain adapter**
   - Replace line naming with a `MarkdownSectionEditor` interface.
   - Group complete and unterminated backtick/tilde fenced blocks losslessly.
   - Expose code language/info and multiline body drafts.
   - Generate a safe closing fence when a code block is changed or created.
   - Keep insert/remove/reorder immutable and retain exact untouched source.
2. **Focused controls**
   - Replace list style buttons with outer `Is list item` and nested `Numbered`
     checkboxes.
   - Add Code block to insertion/type choices with language and multiline code
     fields, including Paste/Copy/Clear behavior that preserves newlines.
   - Rename all visible line wording to section wording.
3. **Section ordering UX**
   - Remove Up/Down/Above/Below actions and contextual insertion forms.
   - Keep one append-section control and move its result by drag.
   - Add a conventional grip, Pointer Event ordering, auto-scroll assistance,
     before/final insertion indicators, keyboard ordering, and live feedback.
4. **Regression and delivery**
   - Cover code-block grouping, round trips, safe fence generation, and whole
     section movement in unit tests.
   - Update CSS, README, specification, changelog, and task history.
   - Run check, all tests, production build, scripted desktop/mobile pointer and
     keyboard interactions, then commit selected changes through GitButler.
