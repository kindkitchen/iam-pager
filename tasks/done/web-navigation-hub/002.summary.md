# Navigation hub, dedicated publish route, modelled delivery control

## Model layer (`lib/ui/`)

- `site-map.ts` — single declaration of every destination with `audience`,
  `group`, `in_navigation`, `in_hub`; `SiteMapReader` interface with a
  session-driven implementation and `is_current_destination`.
- `site-navigation.ts` — top navigation is now derived from the map instead of
  a hard-coded list. Guest sign-in and CSRF logout behavior unchanged.
- `site-home.ts` — `SiteHomePresenter` projects the map into grouped hub
  sections (`create`, `discover`, `learn`, `account`) with one primary card per
  group.
- `site-editorial.ts` — one `SiteEditorialPresenter` for about, demo, and
  invite; invite is session-dependent (guest pitch vs creator next steps).
- `site-breadcrumb.ts` — added `publish`, `about`, `demo`, `invite` locations.
- `page-content-type.ts` — `PdfDeliveryProfileOption` gained `description`;
  `attachment` label is now `Download`.

## Routes

- `/` and `/site` render the hub only (`components/SiteHome.tsx`); no publish
  form, no management panel.
- New `/site/publish` (full width), `/site/about`, `/site/demo`,
  `/site/invite`.
- `/site/manage` additionally renders the namespace reservation panel.

## Components

- `SiteApp.tsx` removed; `SiteNavigation.tsx` now exports
  `SiteSessionNavigation` plus the shared `SitePageHeader` used by every
  destination.
- `DeliveryProfileField.tsx` replaces the bare `Downloadable` checkbox in both
  `PagePublishForm` and `PageManagementPanel` ("Edit paths"); publish state now
  stores `delivery_profile` instead of a boolean.
- CSS: shared `.choice-group/.choice-options/.choice-option`, `.toggle-field`
  (external-content filter, Markdown list toggles), hub and editorial styles;
  `.hero` replaced by `.site-page-header`.

## Verification
