# Rearrange web navigation

Requested changes:

1. Home page is the navigation hub: About, Demo, Explore, Publish, Manage, API
   keys, and a guest-only Invite entry. New destinations are created as part of
   the change.
2. Page generation gets its own web route so the publish surface has more space
   and more layout freedom; home no longer embeds publishing or management.
3. The `Downloadable` checkbox in "Edit paths" is ugly; the same bare-checkbox
   pattern elsewhere is fixed with it.

Constraints from the project conventions: logic lives in `lib/` behind
interfaces, components render server-owned models, snake_case properties,
kebab-case files, CamelCase components.
