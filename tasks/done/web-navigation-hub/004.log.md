# Publish-surface follow-up

Feedback after the first pass:

1. The "Unreserved pages remain unprotected" notice was shown to creators too.
   It is now guest-only (`components/PublishPage.tsx`); creators can publish only
   into namespaces they own, so the warning never applied to them. Covered by
   `lib/ui/publish-page-component.test.tsx`.
2. Editing space: the Markdown/CSS and Raw/Steps tab pairs each drew their own
   box. `markdown-mode-panel` lost its frame, padding, and background; the
   Raw/Steps switcher became a segmented control that shares the tab row on
   screens >= 48rem (absolutely positioned over the tab strip). Both tab groups
   still exist and keep their tablist semantics.
3. Space and centring: `.publish-page-shell` is a centred `108rem` shell,
   `.publish-panel` is single-column (the 70rem two-column split was removed),
   setup fields cap at `64rem` and form a three-column band above `90rem`, and
   editor/preview heights are `clamp(20rem, 54vh, 46rem)`.
4. Chrome removed: the in-form "Create a page" heading duplicated the page
   header; the separate editor toolbar row merged into the editor heading
   (`page-editor-controls`); layout labels became "Editor and preview" /
   "Editor only"; "Add alias" is compact instead of full-width.

Verified with `deno task check`, `deno task test` (684), and headless Chromium
screenshots at 1700px, 1600px, and 430px.
