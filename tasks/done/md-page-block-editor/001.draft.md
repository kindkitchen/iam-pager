# Extend MdPage with step-by-step editing

Add an optional mobile-first editor alongside the existing raw Markdown
textarea. Represent content as compact line previews with controls to edit,
delete, reorder, and insert above or below. The insertion flow should offer
common Markdown items, including headings, lists, links with separate label and
URL fields, and plain text.

The conversion between Markdown and structured items must be deterministic in
both directions. Raw Markdown remains the source passed to preview and
publishing, so existing content behavior and domain logic do not change.
