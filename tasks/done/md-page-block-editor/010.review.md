# Paste fallback completed

Paste still uses `navigator.clipboard.readText()` for the one-tap path. If that
API is unavailable or rejects, the browser now opens an explicit prompt where
the user can paste manually and confirm. Both paths normalize line breaks to
spaces before updating the physical-line field and report their result.

Verification: `deno task check`, all 86 tests, and `deno task build` pass.
Scripted Chromium checks passed for both a permitted real clipboard read and a
forced read failure handled through the manual prompt, including multiline
normalization.

Ready for review.
