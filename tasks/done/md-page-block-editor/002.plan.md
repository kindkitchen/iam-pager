# Implementation plan

1. Add a UI-independent line model and converter that losslessly round-trips
   arbitrary Markdown by retaining each physical line while recognizing common
   item shapes for focused forms.
2. Add unit coverage for round trips, recognized forms, mutation helpers, and
   link escaping behavior.
3. Add a switchable structured mode to `PageEditor`, with compact previews and
   touch-sized edit, move, delete, and contextual insertion controls.
4. Keep every structured mutation flowing through the existing
   `on_markdown_input` callback.
5. Update mobile-first styling and project documentation, then run format, lint,
   type, test, and production build checks.
