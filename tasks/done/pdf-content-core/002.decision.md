# PDF does not generate endpoint locators

Superseding the endpoint-planner wording in [[001.draft]], the PDF capability
validates bytes/metadata and declares supported delivery profiles. Publishers
supply ordinary endpoint locators and choose a profile for each. `.pdf` has no
special meaning. The generic page endpoint service validates and persists the
complete configured set; the PDF handler never creates paths.
