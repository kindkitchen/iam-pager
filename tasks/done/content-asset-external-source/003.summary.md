# External content asset source implemented

`ContentAsset` now discriminates explicit inline data from payload-free external
references. External assets require bounded provider references, local SHA-256,
and a content codec version; `content_asset_violation` rejects mixed or malformed
shapes.

Memory and Deno KV repositories satisfy shared conformance for both source kinds.
KV external manifests contain no encoded-data locator or payload object and
bypass the inline data codec. Strict decoding maps legacy source-less manifests
to `{ kind: "inline" }` without migration and rejects external manifests carrying
payload fields.

Existing page publication writes explicit inline sources. Page materialization
fails closed for external assets until the delivery resolver task lands.
Documentation and the changelog reflect that asset persistence is implemented
while the user-facing capability remains unavailable.

Verification: `deno task verify` passed all 575 tests and 13 steps.
