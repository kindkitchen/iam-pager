# Completed verified immutable-asset staging

Pinned `@olli/kvdex` 3.6.7 and added an adapter-owned schema over a caller-owned
Deno KV. `KvdexContentAssetRepository` satisfies the existing asset create/read
interfaces without exposing Kvdex: it V8-serializes data, writes encoded segments
under a random staging ID with batched operations, reconstructs and verifies
length/SHA-256/decoding, then publishes a separate unencoded manifest.

Failed known batches receive pinned-layout best-effort cleanup and never publish
an asset identity; an ambiguous manifest commit retains its payload rather than
risk breaking a commit that succeeded remotely. Reads fail closed on malformed
manifests, missing payloads, changed length/hash, or invalid serialization.
Focused tests cover immutable conflicts and isolation, 1 MiB cross-instance
segmentation, injected partial-batch interruption/cleanup/retry, corruption, and
legacy raw-keyspace coexistence. All 499 tests, check, and production build pass.

Deployment composition is deliberately unchanged. Next: implement unencoded
page/endpoint/owner/public documents with one complete conditional visibility
commit, run the unchanged aggregate conformance against Kvdex, then add explicit
raw-keyspace compatibility/migration before selecting the adapter.
